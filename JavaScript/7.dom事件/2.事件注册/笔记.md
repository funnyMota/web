# 事件注册

事件绑定

## dom0

将时间名称前面加上on,作为dom的属性名,给该属性赋值为一个函数,即为事件注册

移除: 重新给事件属性赋值,通常赋值为null和undefined


## dom2

dom对象.addEventListener: 注册事件

与dom0的区别
1. dom2可以为某个元素的同一个事件,添加多个处理程序
2. dom2运行开发者控制事件处理的阶段,使用第三个参数,表示是否在捕获阶段触发
  1. 如果元素是目标元素(事件源),第三个参数无效

时间的移除: dom对象.removeEventListener(事件名,处理函数  )

**dom2中如果要移除时间,不能使用匿名函数**

**细节**:
1.dom2在IE8及以下不兼容,需要使用attachEvent,detachEvent,来添加和移除事件
2.添加和移除事件时,可以把第三个参数写入个对象,继续相关配置
