# 变量和对象

- **原始类型**：`number`、`string`、`boolean`、`undefined`、`null`
- **引用类型**：`object`、`function`

## 在变量中存放对象

### 1. 通过变量读取对象中的某个属性

```javascript
变量名.属性名
```

> **注意**：
> - 当读取的属性名不存在时，会得到 `undefined`
> - 当读取的属性对象不存在（`undefined` 或 `null`）时，会报错

### 2. 通过变量更改对象的属性值

- 当赋值的属性不存在时，会**添加属性**

### 3. 删除属性

```javascript
delete 属性名.变量名
```

### 4. 属性的表达式

给属性赋值、读取属性时，可以使用下面的格式操作：

```javascript
对象变量["属性名"]
```

- 某些属性名包含特殊字符
- JS 中属性名的要求并不严格，可以是任何形式的名字

> **属性的名字只能是字符串，如果是数字会自动转化成字符串**

## 全局变量

JS 大部分宿主环境，都会提供一个特殊的对象，该对象可以直接使用，叫做**全局对象**

- 在浏览器环境中，全局对象为 `window`，表示整个窗口
- 全局对象中的所有属性，可以直接使用，而不需要写上全局对象名

> **重要**：
> - 开发者定义的所有变量，实际上，会成为 `window` 对象的属性
> - 如果变量没有被赋值，则该变量不会覆盖 `window` 对象上的同名属性
