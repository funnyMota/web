# 数据和数据信息

数据: 有用的信息
数据类型: 数据的分类

## JS中的数据类型

### 原始值类型(基本类型)

1. 数字类型number

数据类型可以加上前缀表示进制
0:表示八进制
0x:表示十六进制
0b:表示二进制

2. 字符串类型string
- 单引号'
- 双引号"
- 模版字符`
在字符串中还有一种转义字符

3. 布尔类型boolean
布尔类型有两种true和false 

4. undefined类型
表示未定义,不存在

5. null类型
表示空,不存在

> 区分某些长数字和字符串: 如果按照数字的类型读则用数字类型,否则用字符串类型
### 引用类型
引用类型有两种:

- 对象Object (事物,东西)

- 函数

## 打印数据的类型
在数据前加上typeof
>js的bug(特征): typeof null得到的是object

## 字面量
直接书写的具体的数据就叫字面量
