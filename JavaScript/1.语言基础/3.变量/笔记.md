# 变量

## 什么是变量

变量是一块内存空间，用于保存数据

## 如何使用变量

### 1. 声明变量

```javascript
var 变量名;
```

> **变量声明后，默认值为 `undefined`**

### 2. 给变量赋值

向变量的内存空间中存放数据

- 变量的值是可变的

## 变量的名称

在开发中，凡是需要自行命名的位置，叫做**标识符**

1. 只能以英文字母、下划线 `_`、`$` 开头
2. 其他位置可以出现数字、英文字母、下划线、`
3. 标识符必须做到**见文知意**

## 语法糖

- 语句可以写在一行中
- 多条语句可以一起声明

## 重要概念

- **任何可以书写数据的地方，都可以放变量**
- 若使用一个未声明的变量，会导致错误
  - **例外**：`typeof 未声明的变量` 会输出 `undefined`
- **JS 中存在变量提升**
  - 所有变量的声明自动提到代码的最顶部
- JS 中允许定义多个同名变量
