# Array构造器

凡是通过Array构造函数创建的对象,都是数组

## 静态成员

- from方法: 可以将一个伪数组转换为真数组
- isArray方法: 判断一个给定的数据是否是真数组
- of方法: 类似于中括号创建数组,依次赋予数组每一项的值

## 实例成员

- fill: 静态填充数组元素
- pop: 弹出末尾一元素
- push: 尾部压入新元素
- reverse: 数组元素逆序排
- shift: 移除首部一元素
- sort: 数组元素排序法
- splice: 删除替换加插入
- unshift: 头部插入新元素

纯函数、无副作用函数: 不会导致当前对象发生改变

- concat: 连接数组返新数组
- includes: 判断是否含某值
- join: 数组转字符串连
- slice: 截取片段返新数组
- indexOf: 正向查找元素位
- lastIndexOf: 反向查找元素位
- forEach: 遍历数组每一项
- every: 数组满足所有条件
- some: 数组一个满足条件
- filter: 过滤得到满足条件的新数组
- find: 查找第一个满足条件的元素,返回元素本身,如果没有找到,返回undefined
- findIndex: 查找第一个满足条件的元素,返回元素下标,如果没有找到,返回-1
- map: 映射,得到一个新数组,新数组每一项都是对象
- reduce: 统计,累计
