# 数组

数组用于存放多个数据

## 创建一个数组

1. new Array(长度)
长度,数组里面的数据总度,一定是一个非负的整数

new Array(数据,数据,数据....)
创建一个数组,并初始化其每一项的值
数组项:数组中每一项的值

2. [数据,数据,数据,...]

创建一个数组,并初始化每个数据的值

## 认识数组的本质

数组的本质是一个对象

- length属性表示数组的长度
- 数字字符串属性:叫做下标,也叫做索引,相当于数组中每个数据的编号,下标从零开始排列

连续下标的取值范围0~length-1,如果给length赋值,会导致数组可能被截断

## 下标
通常情况下,下标是连续的
x下标不连续的数组,叫做稀松数组

## 数组的常见操作

### 添加数组项
- 数组[长度] = 数据:向数组末尾添加数据
- 数组.push(数据):向数组末尾添加数据
- 数组.unshift(数据):向数组开头添加数据,数组的每一项会往后移一位 
- 数组.splice(下标,0,添加的数据):从指定下标位置开始,删除0个,然后再该位置插入添加的数据,如过下标超过范围,则按边界处理

push\unshift\splice可以添加多个数据

### 删除数组项
- delete arr[索引]:这种做法不会导致数组其他属性发生变化,因此该做法会导致产生稀松数组,所以不推荐使用该做法
- 数组.pop():删除数组最后一项,并返回最后一项的值
- 数组.shift:删除数组第一项,并返回第一项的数据
- 数组.splice(下标,删除的数量,添加数据):从指定下标位置开始,删除指定数据,然后再该位置插入添加的数据,如过下标超过范围,则按边界处理。返回一个新数组,该数组记录被删除的数据


### 其他操作

- 数组.slice(起始位置,结束位置下标): 将起始位置和结束之间的数据拿出来,得到一个新数组,原数组不变; 注意:结束下标娶不到,可以用于复制数组

下标可以写负数,如果是负数,则从数组的末尾开始计算

- 数组清空
数组.splice(0,数组.length);
数组.length=0; 

- 查找数组中某一项的下标
数组.indexOf(数据)
从数组依次查找数据,找到第一个匹配的下标,如果未找到则得到-1;

数组.lastIndexOf(数据)
查找最后一个匹配的下标

- 数组.fill

数组.fill(数据):将数组的所有项,填充数据
数组.fill(数组,开始下标):从开始下标起,填充数据
数组.fill(数组,开始下标,结束下标):从开始下标起到结束下标(取不到结束下标),填充数据

- 数组.join

- 数组.concat

## 语法补充

### in关键字

判断某个属性在对象中是否存在
属性名 in 对象
返回一个boolean

### for-in循环

```js
for(var prop in 对象){

}
```
取出对象的所有对象名,每次循环将其中一个属性名赋值给prop

**区别for in可以获取到稀松数组**
