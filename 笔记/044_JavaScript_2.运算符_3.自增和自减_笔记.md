# 自增和自减

## 基本功能
++: 将某个变量+1
--: 将某个变量-1

## 细节

### 自增自减表达式

x++: 将变量x自增1，返回表达式之前的值
++x: 将变量x自增1，返回表达式之后的值
x--: 将变量x自减1，返回表达式之前的值
--x: 将变量x自减1，返回表达式之后的值

### 优先级

从高到低依次是
1. ```++ --```
2. ```* / %```
3. ```+ -```

优先级的运算细节

1. 从左到右依次查看
2. 如果遇到操作数,将数据的值直接取出
3. 如果遇到相邻的运算符,并且左边的运算符优先级等于右边运算符,则直接运行左边的运算
