# 第一个 JS 程序

## 引入方式

1. 写到 `<script>` 元素里面
2. 写到外部 JS 文件中，在页面中引用（推荐）

> **代码分离**：内容、样式、功能三者分离，更加容易维护和阅读

## 语法

- 如果一个 `<script>` 元素引入了外部文件，则内部不能写入任何代码
- `<script>` 有个属性叫 `type`，该属性用于指定代码的类型，属性值是 MIME 格式

## 认识输出语句

> 所有的输出语句都不是 ES 标准

- `document.write` — 将数据输出到页面
- `alert` — 将数据用于弹窗显示
- `console.log` — 将信息输出到控制台
