# 运算符概述

变量和数据类型，解决数据存放的问题
运算符，解决数据运算的问题

## 操作符和操作数

操作符: 运算符,参与运算的符号
操作数: 参与运算的数据,也称之为元

操作符
`.`访问对象的属性
`=`给变量赋值
`[]`访问对象的属性
`()`函数的调用

## 分类

功能区分:
1. 算术运算符
2. 比较运算符
3. 逻辑运算符
4. 位运算符

## 表达式

表达式 = 操作符+操作数

每个表达式都有返回结果叫**返回值**,返回的类型就叫**返回类型**

1. ```=```: 该表达式,返回赋值的结果
2. ```.```: 属性访问表达式,返回属性的值
3. ```[]```: 属性访问表达式,返回属性的值
4. ```()```: 函数调用表达式,返回的结果取决于函数的运行

console.log函数调用的返回值是undefined

当在浏览器书写代码时,还会返回表达式的返回结果
