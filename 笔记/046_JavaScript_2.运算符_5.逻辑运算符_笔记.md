# 逻辑运算符

## 与(并且)
符号:&&
书写方式: 表达式1 && 表达式2

1. 将表达式1 进行 boolean 判定
以下数据均判定为false:
1) null
2) undefined
3) false
4) NaN
5) ''
6) 0
其他数据全部为真

2. 如果表达式1的判定结果为假,则直接返回表达式1,而不执行表达式2;否则,返回表达式2的结果
(短路规则)

## 或
符号:||

写法: 表达式1||表达式2
1. 将表达式1进行boolean判定
2. 如果表达式1为真,就直接返回表达式1,不执行表达式2;
否则,返回表达式2


## 非

符号:!
写法:!数据
将数据的boolean判定结果直接置反
