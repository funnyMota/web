# 数据和数据类型

- **数据**：有用的信息
- **数据类型**：数据的分类

## JS 中的数据类型

### 原始值类型（基本类型）

#### 1. 数字类型（number）

数据类型可以加上前缀表示进制：

- `0` — 表示八进制
- `0x` — 表示十六进制
- `0b` — 表示二进制

#### 2. 字符串类型（string）

- 单引号 `'`
- 双引号 `"`
- 模板字符串 `` ` ``

> 在字符串中还有一种转义字符

#### 3. 布尔类型（boolean）

布尔类型有两种：`true` 和 `false`

#### 4. undefined 类型

表示未定义，不存在

#### 5. null 类型

表示空，不存在

> **区分某些长数字和字符串**：如果按照数字的类型读则用数字类型，否则用字符串类型

### 引用类型

引用类型有两种：

- **对象（Object）** — 事物、东西
- **函数（function）**

## 打印数据的类型

在数据前加上 `typeof`

> **JS 的 bug（特征）**：`typeof null` 得到的是 `object`

## 字面量

直接书写的具体的数据就叫**字面量**
